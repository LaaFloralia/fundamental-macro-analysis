# USOIL チャート外分析

`usoil/` は既存の表示・検証部品を使うWTI原油の独立パッケージです。BTC・本体・共用スクリプトは変更しません。M2はコードとオフライン試験、M3は実データからMD・HTML・machine.jsonを作り親が実物を確認する段階です。実走・目視の成否は親の検証記録で確認してください。

**M4は未接続です。** ジョブのinstall、定期起動、Journal、共用ダッシュボード、DOT、HP公開はまだ行いません。設定やローカル出力を本番稼働と扱わないでください。

## データと判断

方向は「ドル・実金利」「EIA在庫・限月構造」「原油固有の一次イベント」の3群です。8項目のスコアと停止ゲートはコードが決め、親は根拠付きの解釈とニュース選別を記入します。COT混雑・OVX急変は減点材料で、独立した方向票ではありません。閾値・確度は初期値で、収益性や的中率は未検証です。

参照価格はCNBC `@CL.1`。取得不能時だけYahoo `CL=F`へ縮退し、確度を制限します。Yahoo OHLCは連続限月でロールが混在するため、CNBCとの限月整合、目的地の上下・距離、最寄り未到達、週間レンジ内位置は未確認です。FREDのWTI/Brent現物は参照価格にも採点にも使いません。

前日・前週・前月の高安はET日付の日足から計算します。前週は月〜金の5本が揃う場合だけ確定し、不足は `window_incomplete` です。日足は3か月を要求しますが、欠測や祝日を補完しません。17:00 ETのメンテ欠測と形成中バーを除き、セッション高安は作りません。ラウンドは参照価格±3%の$1刻みで、$5刻みを主要水準として表示します。定着の継続時間は連続した確定H1だけで測り、日足終値だけなら継続時間は未確認とします。

在庫実績はEIA WPSR CSV、COTはDisaggregated Futures OnlyのWTI-PHYSICAL NYMEX（067651）です。COTは火曜基準の週次値で、鮮度・履歴不足を表示します。OVX日次変化はCboe現在値と、その観測日より前のFRED終値から算出し、引け後のCboe `previous=current`を変化ゼロの根拠にしません。VIX・S&P 500・HY OASは表示のみ。リテールは未実装、Baker Hughes・OPEC直源・板・オプション建玉は不採用です。

OPEC会合は取得済み本文の同じ文に年・日付・時刻・UTC/GMTまたは数値時差が明示された予定だけを暫定窓にします。日時が曖昧なら未確認として残し、公表時刻を会合時刻へ代用しません。FFの重要な行が壊れている場合も完全な予定表と扱わず、次24時間を保留します。限月比較が未確認の高安・ラウンドは目的地へ選択できません。

ニュースはInvesting news_11/news_14、OilPrice main、EIA todayinenergy、CFTC rssgpを使います。本文取得は固定ホストのHTTPSだけを許可し、SSRFと外部本文内の指示への対策を保持します。Investing本文は取得しません。原油1分足は未取得なので、公表前後の分単位反応は欠測です。見出しだけの地政学材料を一次確認済みの原油イベントへ加点しません。

## 作成・確認

親の手順は `usoil/job_template/PARENT-WORKFLOW.md` です。request → parent-package → parent-review → latest の契約を保ちます。入力ハッシュ、MD・machine一致、スキーマ、図とfactの数値対応、PC・スマホの画像、親レビューの実体を検査します。共通6フィールド（bias/no_trade/no_trade_reason/risk_events_next_24h/positioning_summary/confidence）は維持します。

HTMLは既存のタイル、バイアス表、参考水準、ニュース、イベント表を流用します。表示文字列はMD第11章へ残し、数値は元factへ結び付けます。PCの描画確認とiPhone実機確認は別です。親の自己レビューを独立レビューとは呼びません。

Jev/D1など別提供元への呼出しは既定オフです。`USOIL_ENABLE_AI_AUX=1`、D1は追加で `USOIL_D1_ENABLED=1` が必要です。共有D1のUSOIL用途は未登録で、フラグだけでは実提供元へ接続しません。接続はM4以降の別判断です。M3では呼び出しません。自動提供元切替・新規課金を行わず、Brain読書き・外部公開・売買の禁止を維持します。

既知ニュースと未解決障害は親受入後に `history/usoil-known-news.json` と `usoil-incidents.json`へ保存します。壊れた履歴は空へ置き換えず `carry_state_invalid` で保留します。障害解除は一次復旧発表と対象ソースの復旧後観測が必要です。owner指定の手動解除は履歴・理由を保持し、親が独断で実行しません。
